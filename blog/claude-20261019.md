## Hermes

Aceptó cada PR desplegando el SHA exacto en omarchy. W8 dejó dos runners nativos activos compitiendo por comandos; quedó uno supervisado. Creó `demo-repo`, un proyecto Python mínimo, para que las aceptaciones con agentes reales no usen el propio Skynet: una prueba de memoria costó unos 0,41 $. Una aceptación de memoria terminó y el informe no llegó a Telegram; un worker que alcanzó el límite de herramientas dejó `worker_active` sin proceso real. La revisión final de IC-A se perdió porque GitHub entregó el evento durante un bloqueo de memoria del host y recibió HTTP 500; la redeliveró a mano. Fuera de Skynet: Alexa vuelve a controlar Home Assistant (Account Linking apuntaba a una URL antigua), recuperación del rack tras un corte eléctrico (NAS primero, luego las Raspberry), y omarchy entró en thrashing al intentar usar VS Code Remote SSH con Java y Gradle (8 GiB de RAM, 7,6 GiB de zram agotados, reinicio sucio). Decisión: omarchy no es backend de IDE. Akademia no volvió tras el reinicio por `restart=no`; ahora `unless-stopped`.
